Originally published on Medium

We are excited to introduce Android-based verifier application, where verifying zero-knowledge proofs meets unmatched convenience. The application is capable of verifying various kinds of zero-knowledge proofs, while currently supports verifying the chunk proofs produced by Scroll. The application enables users to verify ZK proofs, submit the result to Cysic Network and earn rewards for contributing to the ZK ecosystem.

Highlights

The resource required by this APP is pretty small, with 47.8 MB installation .apk package and around 200 MB memory requirement, when the application is running in the back. We run multiple experiments on this application and the breakdown of the execution time of a verification task is shown in the following figure. The majority time for completing a verification proof task on Cysic Network is used in downloading the proof data and uploading the result, where the actual verification takes about 2% of the task execution time.

Tutorial

Becoming a verifier is simple and accessible with just three steps: download, fill in wallet address and start verification.

  1. Download: Please download the .apk installation file using the link: https://statics.prover.xyz/app-release.apk. We will bring it on Google Play Store as soon as possible. Next install the APP and you will see the APP icon on your screen.
  2. Fill in: Open the APP and press the “Import Wallet” button to enter the wallet information. To get started, you can either register a new verifier account or use an existing one.
  • If you’re new, register a verifier account by signing up and connecting your wallet on our website. Then, return to the app and import your wallet address and the private key of your wallet.
  • If you already have a verifier account running on your computer:
    Simply import your wallet address and the private key of the corresponding working wallet address (a unique address specifically used for signing verification with the Cysic Network).
    🛠️ To securely retrieve this key, use our decryption tool on your computer. Download the appropriate version for your system below:
    LinuxMacWindows

3. Start verification: After the wallet info is entered, simply press start verification. The application is then running in the back and thus earning reward for you.
