Recommend Hardware Requirements for Prover Program Installation

To ensure a smooth installation and operation of the Prover Program, make sure your device meets these minimal specifications:

  • CPU: 64-thread CPU
  • GPU: 2 × 3070/2080 GPUs
  • Memory: 280 GB
  • Disk: 100 GB SSD
  • Bandwidth: 100 KB/s upload/download
  • Supported Operating Systems: Linux

We encourage all participants to test the Prover program with their current hardware setup. If the program does not run successfully in less than 1 hour, it may indicate that your hardware does not meet the recommended specifications.

How the Prover Works:

The provers operates using a fair and efficient round-robin system:

  • For each task, 3 provers are selected and rewarded

This structure rewards speed and participation, encouraging engagement and ensuring task completion efficiency.

To qualify as an activated user, verifiers must complete 10 verification tasks. These requirements ensure active participation and high-quality contributions to the Cysic Network. Invite your friend to get 15% of their reward and help them activate their account!

Operating the Prover Node Program

TL;DR to execute prover on Linux:

Open the terminal and run the following commands to setup and execute the Prover Program.

# replace 0x-Fill-in-your-reward-address-here to your reward address below
curl -L https://github.com/cysic-labs/phase2\_libs/releases/download/v1.0.0/setup\_prover.sh >
~/setup_prover.sh && bash ~/setup_prover.sh 0x-Fill-in-your-reward-address-here

cd ~/cysic-prover/ && bash start.sh

Detailed steps to execute prover on Linux:

First start your terminal program on Linux. The shortcut is Ctrl-Alt-T on Ubuntu. Or you can search for it in the applications and click on Terminal to start it.

Step 1: Use the following command in the terminal to download and run the setup script. Copy the code below, replacing the address placeholder with your reward address, then paste it to run it in your terminal.

# replace 0x-Fill-in-your-reward-address-here to your reward address below
curl -L https://github.com/cysic-labs/phase2\_libs/releases/download/v1.0.0/setup\_prover.sh >
~/setup_prover.sh && bash ~/setup_prover.sh 0x-Fill-in-your-reward-address-here

This script will do the following job:
1. Download the prover program and library: prover libcysnet_monitor.so libdarwin_prover.so & libzkp.so 2. Create the prover config file named config.toml config.toml 3. Create script to run the prover: start.sh

You can go to ~/cysic-prover folder to see all the above contents created successfully after running the script.

Step 2: Once the download from Step 1 is completed, copy and paste the below code, press enter to run.

cd ~/cysic-prover/ && bash start.sh

The prover may take a few minutes to connect to the chain. While it’s establishing a connection, you may see an “err: rpc error” message.

Don’t worry — just wait a few minutes for the prover to connect. Once connected, you’ll see a message like “start sync data from server,” indicating it is running successfully.

To reconnect the prover: execute Step 2 again.
The Prover Program will create mnemonic files for you. Your submitted address mnemonic file is in: C:\Users\username\.cysic\keys folder, please keep it or you can not run the Prover Program again.
