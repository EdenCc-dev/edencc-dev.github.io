Join the Cysic Testnet as a Verifier

Jul 29, 2024

As the previous introduction of the Cysic network illustrated, the step-by-step Testnet verifier onboarding process is shown below figure:

Submit your application

Ⅰ. Open our Testnet website.

🔗: https://testnet.cysic.xyz/m/register

Ⅱ. Click the “𝗖𝗼𝗻𝗻𝗲𝗰𝘁 𝗪𝗮𝗹𝗹𝗲𝘁” button, and confirm the connection.

Ⅲ. After connecting your wallet, please select the “𝗩𝗲𝗿𝗶𝗳𝗶𝗲𝗿” button.

Ⅳ. Submit your information.

Ⅴ. Certify your address, then click “ 𝗖𝗼𝗻𝗳𝗶𝗿𝗺**”,** sign this then wait for the backend confirmation.

Ⅵ. Check whether your address is accepted or not on Cysic Dashboard.

🔗: https://testnet.cysic.xyz/m/dashboard/verifier

Preparing the environment to join the Testnet

Requirements:

Ensure your device meets the following minimal specs for a smooth Cysic verifier program installation:

  • CPU: Single Core
  • Memory: 512 MB
  • Disk: 10 GB
  • Bandwidth: 100 KB/s upload/download
  • Available OS: Linux, Windows, Mac

𝗧𝗵𝗲 𝗢𝗦 𝗰𝗮𝘁𝗲𝗴𝗼𝗿𝘆 𝘄𝗶𝗹𝗹 𝗯𝗲 𝗽𝗮𝗿𝗮𝗹𝗹𝗲𝗹𝗹𝘆 𝗶𝗹𝗹𝘂𝘀𝘁𝗿𝗮𝘁𝗲𝗱 𝗶𝗻 𝘁𝗵𝗲 𝗳𝗼𝗹𝗹𝗼𝘄𝗶𝗻𝗴 𝗽𝗿𝗼𝗴𝗿𝗲𝘀𝘀.

Operating the Verifier Node Program

If the backend confirms your address, please follow the steps to download the verification program. The program size is about 4GB, please be patient in downloading.

Ⅰ. Open the terminal on your OS, then execute the program on your terminal line by line ❗

Linux:

rm -rf ~/cysic-verifier
cd ~
mkdir cysic-verifier
curl -L https://cysic-verifiers.oss-accelerate.aliyuncs.com/verifier\_linux > ~/cysic-verifier/verifier
curl -L https://cysic-verifiers.oss-accelerate.aliyuncs.com/libzkp.so > ~/cysic-verifier/libzkp.so

Mac:

rm -rf ~/cysic-verifier
cd ~
mkdir cysic-verifier
curl -L https://cysic-verifiers.oss-accelerate.aliyuncs.com/verifier\_mac > ~/cysic-verifier/verifier
curl -L https://cysic-verifiers.oss-accelerate.aliyuncs.com/libzkp.dylib > ~/cysic-verifier/libzkp.dylib

Windows:

❗We recommend you use the “𝗣𝗼𝘄𝗲𝗿 𝗦𝗵𝗲𝗹𝗹 𝗧𝗲𝗿𝗺𝗶𝗻𝗮𝗹”

❗Terminal needs to be run with 𝗮𝗱𝗺𝗶𝗻𝗶𝘀𝘁𝗿𝗮𝘁𝗼𝗿 𝗿𝗶𝗴𝗵𝘁𝘀

cd $env:USERPROFILE
New-Item -ItemType Directory -Force -Path "cysic-verifier"
Invoke-WebRequest -Uri "https://cysic-verifiers.oss-accelerate.aliyuncs.com/verifier\_win\_x86\_64.exe" -OutFile "cysic-verifier\verifier.exe"
Invoke-WebRequest -Uri "https://cysic-verifiers.oss-accelerate.aliyuncs.com/libzkp.dll" -OutFile "cysic-verifier\zkp.dll"
Invoke-WebRequest -Uri "https://cysic-verifiers.oss-accelerate.aliyuncs.com/start.ps1" -OutFile "cysic-verifier\start.ps1"

Note for Mac Users:

If a prompt appears on your Mac (as shown in the image below), follow these steps:

About Cysic

Cysic is an industry-leading ZK hardware acceleration project, dedicated to designing advanced ASIC chips to help reduce ZK proving generation time and become the first ZK Prover Network. It is a real-time ZK proof generation and verification layer, that aims to provide ZK proofs in the fastest, cheapest, simplest, and most decentralized way.

Cysic Provides ZK-CaaS (ZK Compute-as-a-Service) based on advanced self-developed ASIC chips and can undertake computing power requirements for all ZK computing scenarios including ZK Rollup, ZKML, ZK Bridge, etc. Based on chip computing power + community GPU computing power, it integrates many verification nodes in the community. Finally, it builds the Cysic Network to provide a credible integrated computing power + verification network for the entire industry.
