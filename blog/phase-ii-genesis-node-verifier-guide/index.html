Phase II: Genesis Node Verifier Guide

Get Started with Cysic Network Phase II Verifier Program

Nov 19, 2024

It’s with great excitement that we share some incredible updates to our verifier program as we release Phase II: Genesis Node. We have made tremendous improvement on light client state proof verification allowing users to run as a verifier in just 2 simple steps. These optimization are designed to make your journey with Cysic smoother, faster, and more accessible.

What’s new in Phase II Verifier Program:

  • Ultra-Light Dependency Size: We’ve achieved a breakthrough in optimization, reducing verifier dependencies from a massive 4GB to an incredible less than 400 KB. This means faster downloads, reduced storage requirements, and a seamless experience for a wider range of users.
  • Effortless Usability: We’ve designed the setup process to make it as simple and user-friendly as possible. With our newly designed scripts, you can get your verifier up and running in just a few steps — no technical expertise required.

We believe these updates are a transformative step forward for the Cysic Network, embodying the potential of blockchain to empower everyone to seamlessly participate in decentralized ZK proving and verification. We can’t wait for you to experience Phase 2 firsthand.

How the Verifier Works:

The verifier operates using a fair and efficient round-robin system:

  • For each task, 10 verifiers are selected.
  • Reward are awarded only to the first 6 verifiers who complete the task.

This structure rewards speed and participation, encouraging engagement and ensuring task completion efficiency.

To qualify as an activated user, verifiers must complete 10 verification tasks. These requirements ensure active participation and high-quality contributions to the Cysic Network. Invite your friend to get 15% of their reward and help them activate their account!

Operating the Verifier Node Program

Recommend Hardware Requirements for Cysic Verifier Program Installation

To ensure a smooth installation and operation of the Cysic verifier program, make sure your device meets these minimal specifications:

  • CPU: Single Core
  • Memory: 8 GB
  • Disk: 512 MB
  • Bandwidth: 100 KB/s upload/download
  • Supported Operating Systems: Windows, Linux, Mac

Find Your OS below and Get Started!

Below, we’ve illustrated the setup process for each operating system. Locate your OS and follow just 2 simple steps to run your verifier effortlessly!

Windows

TL;DR to execute verifier on Windows:

Open Windows Powershell and run the following commands to setup and execute the verifier program

# replace 0x-Fill-in-your-reward-address-here with your reward address below
cd $env:USERPROFILE
Invoke-WebRequest -Uri "https://github.com/cysic-labs/phase2\_libs/releases/download/v1.0.0/setup\_win.ps1" -OutFile "setup_win.ps1"
.\setup_win.ps1 -CLAIM_REWARD_ADDRESS "0x-Fill-in-your-reward-address-here"

# run the verifier
cd $env:USERPROFILE\cysic-verifier
.\start.ps1

Detailed steps:

First start your terminal program on Windows. Search for it in the applications and start Powershell as administrator. Terminal needs to be run with 𝗮𝗱𝗺𝗶𝗻𝗶𝘀𝘁𝗿𝗮𝘁𝗼𝗿 𝗿𝗶𝗴𝗵𝘁𝘀.

Step 1: Use the following command in the terminal to download and run the setup script (copy and paste the following command in Powershell and press enter to run them). Please replace 0x-Fill-in-your-reward-address-here with your own reward address below.

# replace 0x-Fill-in-your-reward-address-here with your reward address below
cd $env:USERPROFILE
Invoke-WebRequest -Uri "https://github.com/cysic-labs/phase2\_libs/releases/download/v1.0.0/setup\_win.ps1" -OutFile "setup_win.ps1"
.\setup_win.ps1 -CLAIM_REWARD_ADDRESS "0x-Fill-in-your-reward-address-here"

This script will do the following job:
1. Download the verifier program and library: verifier.exe, start.ps1 & zkp.dll 2. Create the verifier config file named config.toml 3. Update Path variable to add cysic-verifier

You can go to ~/cysic-verifier folder to see all the above contents created successfully after running the script.

Step 2: After the completion of Step 1, use the following command in terminal to start the verifier program:

# run the verifier
cd $env:USERPROFILE\cysic-verifier
.\start.ps1

The verifier may take a few minutes to connect to the chain. While it’s establishing a connection, you may see an “err: rpc error” message. Don’t worry — just wait a few minutes for the verifier to connect.

Once connected, you’ll see a message like “start sync data from server,” indicating it is running successfully.

To reconnect the verifier: execute Step 2 again.
The verifier program will create mnemonic files for you. Your submitted address mnemonic file is in: C:\Users\username\.cysic\keys folder, please keep it or you can not run the verifier program again.

Linux

TL;DR to execute verifier on Linux:

Open the terminal and run the following commands to setup and execute the verifier program.

# replace 0x-Fill-in-your-reward-address-here with your reward address below
curl -L https://github.com/cysic-labs/phase2\_libs/releases/download/v1.0.0/setup\_linux.sh >
~/setup_linux.sh && bash ~/setup_linux.sh 0x-Fill-in-your-reward-address-here

cd ~/cysic-verifier/ && bash start.sh

Detailed steps:

First start your terminal program on Linux. The shortcut is Ctrl-Alt-T on Ubuntu.

Or you can search for it in the applications and click on Terminal to start it.

Step 1: Use the following command in the terminal to download and run the setup script. Copy the code below, replacing the address placeholder with your reward address, then paste it to run it in your terminal.

# replace 0x-Fill-in-your-reward-address-here to your reward address below

~/setup_linux.sh && bash ~/setup_linux.sh 0x-Fill-in-your-reward-address-here

This script will do the following job:
i. Download the verifier program and library: verifier & libdarwin_verifier.so ii. Create the verifier config file named config.toml iii. Create script to run the verifier start.sh

You can go to ~/cysic-verifier folder to see all the above contents created successfully after running the script.

Step 2: Once the download from Step 1 is completed, copy and paste the below code, press enter to run.

cd ~/cysic-verifier/ && bash start.sh

The verifier may take a few minutes to connect to the chain. While it’s establishing a connection, you may see an “err: rpc error” message. Don’t worry — just wait a few minutes for the verifier to connect.

Once connected, you’ll see a message like “start sync data from server,” indicating it is running successfully.

To reconnect the verifier: execute Step 2 again.
The verifier program will create mnemonic files for you. Your submitted address mnemonic file is in: C:\Users\username\.cysic\keys folder, please keep it or you can not run the verifier program again.
